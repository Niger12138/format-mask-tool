「格式转换与打码工具」修改报告
仓库：https://github.com/Niger12138（本项目）
工具：格式转换与打码工具.html（单文件本地网页应用）
平台：Windows / 浏览器本地运行，全部处理在本地完成，不上传任何文件
========================================================

【项目定位】
一站式本地图片/PDF 处理工具，集成 7 大功能页签：
  1. 图片打码（批量队列，马赛克/纯色涂抹，框选打码，可撤销）
  2. PDF 打码（逐页框选，归一化坐标记录，高清重绘导出）
  3. 图片转 PDF（多图排序合并，支持跟随原图尺寸或 A4）
  4. PDF 转图片（1x/2x/3x 清晰度，PNG/JPG/WEBP，单页或打包 zip）
  5. 图片格式转换（PNG/JPG/WEBP/BMP/PDF 五种输出，批量）
  6. 图片压缩（最长边限制 + 智能压缩）
  7. PDF 压缩（整份 PDF 智能压缩）
所有导出入口均支持「目标文件大小」：二分搜索质量 + 必要时等比缩尺寸，
自动逼近用户指定大小（如 ≈500KB），现有大小实时显示且目标只能小于现有。

--------------------------------------------------------
一、初版开发
--------------------------------------------------------
- 单文件 HTML 工具，暖橙色玻璃拟态中文界面
- 五大功能：图片打码 / PDF 打码 / 图片转 PDF / PDF 转图片 / 图片格式转换
- 技术栈：pdf.js（读取渲染 PDF）、jsPDF（生成 PDF）、JSZip（打包）
- 打码支持马赛克/纯色涂抹两种模式，拖拽框选、多区域、撤销、清空
- PDF 打码按页存储归一化坐标，导出时 2x 高清重绘（真打码，无法还原）

--------------------------------------------------------
二、功能迭代（按用户反馈）
--------------------------------------------------------
1. 默认打码方式改为「纯色涂抹」（后默认颜色改为白色 #ffffff）
2. 格式转换新增 BMP（手动编码 24 位位图）和 PDF 输出格式
3. 新增「图片压缩」页签（最长边限制 4000/2000/1920/1280/800px）
4. 全部导出入口新增「目标大小」选项（≈100KB~≈5MB）：
   - 图片打码、PDF 打码（整个 PDF 总大小分摊到每页）
   - PDF 转图片（按每页计算）、图片格式转换（按每张计算）
   - 图片压缩、PDF 压缩页签同样支持
5. 压缩策略：先二分搜索质量（5%~95%，约 7-8 次锁定），质量到头
   仍不够小时按 0.8 倍逐步等比缩尺寸重试，最多 8 轮
6. 界面简化：删除全部滑块（强度/质量），马赛克强度固定最高档 40
7. 「现有大小」显示补全所有页签，目标选项 ≥ 现有自动置灰 + 兜底校验
8. 新增「PDF 压缩」页签（每页重渲染 + 分摊压缩，越压越大时提醒保留原文件）
9. 图片打码升级批量模式：多选队列、上一张/下一张切换自动保存进度、
   移除本张、重新选图追加队列；单张时自动隐藏翻页导航
10. 图片打码页精简：移除「本张转 PDF / 全部转 PDF」按钮（嫌臃肿）

--------------------------------------------------------
三、性能优化
--------------------------------------------------------
- 加载提速：4 个引擎（pdf.js / jsPDF / JSZip）从海外 CDN 本地化到
  libs/ 目录（国内源 npmmirror 下载），打开秒级、可完全离线；
  libs 缺失时自动回退国内镜像
- 质量二分搜索结果复用（blob 直接复用），批量转换/压缩提速 10-20%
- PDF 打码 / PDF 压缩导出同样复用搜索结果，多页 PDF 提速 30-50%
- 撤销栈内存上限 300MB（超限自动丢最旧快照），防止大图卡机
- 重新选文件时 doc.destroy() 释放旧 PDF 文档内存

--------------------------------------------------------
四、独立 exe 打包
--------------------------------------------------------
- 使用 PyInstaller + pywebview（Windows 系统 Edge WebView2 内核）
  打包为真正的独立窗口应用（不开浏览器，双击即用，窗口 1180x820）
- 引擎与页面全部内嵌，单文件 37MB 绿色便携，拷到任何 Win10/11 可用
- 应用图标：AI 生成橙色渐变图标（文档转换循环箭头 + 马赛克像素块），
  经 AI 去水印后转多尺寸 .ico（16~256px）打入 exe
- 自检机制：--selftest 参数验证服务启动与页面完整性

--------------------------------------------------------
五、三轮自查与体验走查修复（共 20+ 处）
--------------------------------------------------------
【第一轮 代码自查 10 处】
  1. 目标大小校验失败导致加载遮罩永久卡死（先校验再开遮罩 + try/catch）
  2. PDF 输出不会真正达标（压缩引擎统一"质量到头缩尺寸重试"8 轮）
  3. zip 同名文件互相覆盖（zipUniqueAdd 自动加序号 _2/_3）
  4. 撤销栈内存炸弹（300MB 上限）
  5. 竖图缩尺寸提示不显示
  6. PDF 压缩越压越大不提醒（明确建议保留原文件）
  7. PNG 透明图转 PDF 黑底（统一垫白底）
  8. 一次拖入多图仅用第一张无提示
  9. 文件名 innerHTML 拼接风险（改 textContent）
  10. 重复定义的 fmtSize 清理

【第二轮 用户体验走查 10 + 4 处】
  1. 批量处理进度"黑盒"→ 全部显示"第 x / n 页（张）"实时进度
  2. 危险操作无确认 → 自定义确认弹窗（清空全部/移除本张，支持 Enter/Esc）
  3. 下载后不知文件在哪 → 明确提示"已保存到「下载」文件夹"+实际大小
  4. 打码页工具栏过挤 → 分组重排（打码工具｜输出设置｜导航｜导出｜队列）
  5. PDF 打码显示"已打码页：1、3"（超 8 页自动截断"等 N 页"）
  6. 马赛克模式下自动隐藏颜色选择器
  7. 按钮命名/主次统一（PDF 压缩页"重新选文件"、单页下载为主按钮）
  8. 换文件后旧结果自动清空
  9. PDF 转图片新增 WEBP 格式
  10. 图片转 PDF 重复添加自动去重（全部重复时明确提示）
  补修 4 处：图片加载中禁止导出/框选（防串图同类）、移除本张释放
  撤销快照内存、确认弹窗键盘支持

【第三轮 自查 7 处】
  1. 格式转换/图片压缩页「目标大小」口径统一为"每张"（与置灰判断、
     兜底校验一致，明确显示"平均每张 ≈ X"），并复用公共函数
  2. 透明 PNG 转 BMP 黑底（BMP 白底垫底）
  3. 图片转 PDF 未读取完成的图不再静默丢页（明确警告）
  4. 全部打包时提示跳过了 N 张未打码图片
  5. 重复添加全部重复时的措辞优化
  6. 已打码页标记超长截断
  7. 图片压缩页手写置灰逻辑并入公共函数
