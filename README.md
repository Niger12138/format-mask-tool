# 格式转换与打码工具

一站式**本地**图片/PDF 处理工具：图片打码、PDF 打码、格式互转、图片/PDF 智能压缩。全部处理在浏览器本地完成，**文件绝不上传**。

## 功能

- 🖼️ **图片打码**：批量队列、马赛克/纯色涂抹、框选、撤销
- 📄 **PDF 打码**：逐页框选，高清重绘导出（无法还原）
- 🖼️➜📄 **图片转 PDF**：多图排序合并
- 📄➜🖼️ **PDF 转图片**：1x/2x/3x 清晰度，PNG/JPG/WEBP
- 🔄 **图片格式转换**：PNG/JPG/WEBP/BMP/PDF 批量互转
- 🗜️ **图片压缩 / PDF 压缩**：支持指定目标文件大小（二分质量 + 按需缩尺寸智能逼近）

## 下载

- 💿 **Windows 独立版（推荐）**：到 [Releases](https://github.com/Niger12138/format-mask-tool/releases/latest) 下载 `FormatMaskTool.exe`，双击即用，免安装
- 🌐 **网页版**：下载 `格式转换与打码工具.html` 和 `libs/` 文件夹（保持同目录），双击 HTML 打开即可，可离线使用

## 新特性：默认保存位置

页签栏右侧「⚙️ 设置」可设置默认保存文件夹，开启免打扰模式后所有导出自动存入该文件夹，不再每次弹窗；同名文件自动加编号，不会覆盖。
